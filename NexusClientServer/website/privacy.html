3. Account data

Passwords should never be stored in plain text. The supplied server uses a password-derived hash rather than storing the original password.

9. User agent

The service may store the browser or application user-agent string associated with account activity for security, compatibility, diagnostics, and abuse prevention.

10. Avatar data

If profile images are supported, an avatar or avatar reference may be stored with the account.

11. Session data

Login sessions use a session token stored in a browser cookie. The server keeps active session state for the configured session lifetime.

12. Cookies

The current authentication flow uses a session cookie named nexus_session. It is used to maintain your authenticated session.

13. Cookie security

The session cookie is configured as HttpOnly and SameSite=Lax in the supplied server implementation. HTTPS should be used in production so session traffic is encrypted in transit.
